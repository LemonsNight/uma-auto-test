# 已知限制清单 — VirtualMouse Phase 1

## 输入模型固有

1. **坐标即命中目标**：程序按桌面屏幕坐标解析窗口。如果目标窗口被其它窗口完全遮挡，
   该坐标处的命中窗口是遮挡者，点击会发给遮挡者而不是原目标。
   只支持对"仍可见区域"的后台点击。
2. **最小化窗口不可点击**：窗口最小化后其屏幕矩形移到 `(-32000,-32000)` 附近，
   原坐标不再属于该窗口。程序不会向最小化窗口或系统桌面窗口发送模拟点击。
3. **PostMessage 入队 ≠ 点击生效**：返回成功只表示消息进入目标队列。
   某些程序（游戏、DirectUI、自绘控件、使用 Raw Input 的程序）可能忽略这些消息。
   本 PoC 不把入队成功表述为业务动作成功。
4. **UIPI / 权限差异**：向更高完整性级别或受保护窗口发送消息可能失败（如 `GetLastError=5`）。
   程序记录失败原因，不尝试绕过安全机制。
5. **键盘修饰状态**：鼠标消息的 `wParam` 只携带 `MK_LBUTTON`，不携带 Ctrl/Shift 等修饰键状态。
   本阶段不要求修饰键点击。

## 平台与兼容性

6. **只在当前环境实测**：Windows 11 build 26200 + PySide6 6.12.0 + Python 3.13.5。
   其它 Qt/Windows 组合的窗口标志行为需重新验证；代码已做运行时标志与坐标校验，
   但不保证跨版本完全一致。
7. **混合 DPI 下 Qt 坐标不可直接用于定位**：`QWidget.move()` 会把物理坐标当逻辑坐标缩放。
   已改用 Win32 `SetWindowPos` 并二次校验；跨 DPI 边界时 Qt 会异步改尺寸，
   代码用多次迭代收敛，但极端快速切换显示器时仍可能出现短暂 1px 偏差。
8. **多显示器热插拔 / 分辨率变化**：未实现动态重校准，变化后建议重启程序。
9. **16 位坐标上限**：鼠标消息 `lParam` 只能表示 `-32768..32767` 的客户区坐标。
   超限时拒绝发送并记录错误，不静默截断。

## 功能范围

10. **无赛马娘业务逻辑**：本阶段只是通用桌面 PoC，不识别游戏画面、不做任务流程。
11. **只实现单击**：未实现双击、右键、拖拽、滚轮。
12. **全局热键可能被占用**：`Ctrl+Alt+Shift+K` 若被其它程序注册会注册失败，
    程序在日志中明确报告，不静默降级。
13. **紧急停止后需手动复位**：`stopped` 状态下所有点击与移动都被拒绝，需点击"复位"恢复。
14. **无自动目标追踪**：圆点与点击坐标完全由控制面板给定的桌面坐标决定。

## 验证局限

15. 阶段 5 早期一次"真实鼠标位置"采样受共享桌面外部鼠标活动干扰；
    最终回归采样与独立隔离实验（对照组 + 25 次操作实验组）均通过，已用其作为验收证据。
16. 未在真实游戏、受保护应用、不同权限账户下验证。

## Phase 1.1 新增限制

17. **UP 入队失败的真实场景未实测**：只通过 Mock 验证了补发释放、状态保留与
    原 HWND 失效处理；真实 Windows 桌面未构造该失败场景。
18. **释放补救仅保证入队**：对原 HWND 补发的 `WM_LBUTTONUP` 返回成功不代表目标已释放按键；
    结果对象始终保留 `button_release_uncertain=True`。
19. **父窗口链深度上限 32**：超过上限按安全失败拒绝；极深嵌套的合法应用窗口可能被误拒。
20. **DPI 感知查询依赖 Win10 1607+ API**：在更早系统上若无法查询实际状态，
    只按设置调用结果报告，不冒充 PM aware；未引入 `PER_MONITOR_AWARE_V2`。
21. **共享桌面外部鼠标活动**：测试偶发 1~2px 光标漂移；已在阶段 2/5 测试中加入对照组区分，
    不归因于本程序。隔离测试干净运行时对照组与实验组均不变。

## Phase 1.1 Review Fix 新增限制

22. **Win32 查询异常分支只由 Mock 覆盖**：真实 Windows 下 `GetClassName` / `GetParent` /
    `IsWindow` 异常极少发生，无法稳定复现实测。
23. **RealChildWindowFromPoint 的 API 入参未在真实进程中逐字节断言**：Mock 验证了坐标转换链路，
    真实记事本场景间接通过（插入符变化）。
24. **DPI 查询失败场景仅 Mock 覆盖**：本机查询始终成功；未知状态标记为 UNKNOWN，
    不冒充 PM aware。

## Phase 1.1 Final Review 新增限制

25. **GetAncestor / 候选子窗口查询异常仅 Mock 覆盖**：真实 Windows 下这些异常无法稳定复现，
    已按安全失败策略处理，但无真实异常样本验证。
26. **DPI 线程级回退结果不等于进程级确认**：诊断会明确标注来源；
    本机实测为进程级查询成功，线程回退分支仅 Mock 覆盖。
27. **RealChildWindowFromPoint 真实 API 入参仍未逐字节断言**：真实记事本场景
    `WindowFromPoint` 直接命中 `RichEditD2DPT`，不进入该 API 分支；
    坐标修正仅由 Mock 验证。
